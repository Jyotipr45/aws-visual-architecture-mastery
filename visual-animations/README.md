# 🎬 Visual Animations

Interactive, animated architecture diagrams. Each one is a **single self-contained HTML file**: no install, no build step, no internet needed.

## How to open

- **On your computer:** double-click [`index.html`](./index.html) to open the gallery in your browser.
- **Online:** once GitHub Pages is enabled, visit `https://jyotipr45.github.io/aws-visual-architecture-mastery/visual-animations/`

## Controls in every animation

| Control | What it does |
|---|---|
| ▶️ Play / ⏸ Pause | Start or freeze the data packets flowing through the diagram |
| ⏮ Prev / ⏭ Next | Walk through the flow one step at a time |
| 🐢 Speed | Slow it down to study, speed it up to review |
| 🔍 Click or hover | Opens an inspector card: full name, nickname, port, protocol, and why it connects there |
